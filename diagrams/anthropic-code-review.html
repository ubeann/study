01 What it is

Anthropic's Claude Code team replaced the single human review gate with stacked checks: machines read every line, a risk tier decides how many people approve, and merge queue, flags and one-step reverts catch what slips through. The question moves from "did a human read it?" to "what could go wrong, and which check should catch it?"

02 The usual way vs this

Normal PR review

Write, open PR, wait for a reviewer, a human reads every line, approve, merge, hope. The same attention goes to a typo fix and a billing change. Rollback is painful.

Claude Code team

Claude verifies before the PR and shows output. Parallel AI reviewers vote on findings. Security review and CI block. A classifier sets 0, 1 or 2 human approvals. Flags and staged rollout make undo cheap. Incidents become evals.

03 How it flows

Claude runs tests, shows output→ fresh-context subagent review→ CI + AI review + security review→ risk tier: 0 / 1 / 2 humans→ merge queue re-tests on main→ flag, internal first, latest then stable→ flag off or one-step revert

AI review: several agents hunt bugs in parallel; verifiers vote; style and cleanup findings are dropped; each finding is tagged Important, Nit or Pre-existing and must be fixed or resolved with a reason. The article does not name what each agent focuses on.
