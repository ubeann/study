01 What it is

CLIProxyAPI is a Go proxy that exposes CLI OAuth logins (Claude, Codex, Gemini, Grok, Kimi, Meta, Devin) as OpenAI, Gemini, Claude and Codex-compatible HTTP APIs, round-robin across accounts. T3 Code drives the official agent CLIs, each with its own vendor login. They sit on different layers: one is a model gateway, the other an agent control surface.

02 The usual way vs this

T3 Code path

You, then T3 Code, then the official Claude Code or Codex CLI, then the provider. Each CLI logs in itself, so the subscription is used the way the vendor intends.

CLIProxyAPI path

Any tool, then the proxy on port 8317, then the provider, reusing a stored CLI token outside that CLI. Anthropic's policy forbids routing requests through Free, Pro or Max credentials outside its native apps.

03 How it flows

--claude-login / --codex-login once→ tokens in ~/.cli-proxy-api→ client sends OpenAI/Gemini/Claude-format request→ proxy translates, picks a credential (round-robin)→ provider, billed to that account
