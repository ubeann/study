01 What it is

Eight tools and conventions, each at a fixed point in one AI coding loop: context, plan, build in parallel, package, verify, land. AI made writing code cheap, so review and landing became the slow part; most of these exist to unblock it.

02 The usual way vs this

Usual way

One developer, one branch, one large PR, one human reviewer, all in series. Every instruction is retyped into each chat. The reviewer is the bottleneck as soon as agents start producing code.

Agent loop

Context lives in the repo (AGENTS.md, skills, MCP). Several agents build in separate worktrees, hand back small stacked PRs, a bot does the first review pass, and a merge queue lands the stack as one group.
