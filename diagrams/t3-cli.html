01 What it is

t3 installs, runs and maintains the T3 Code server, the control surface that drives Codex, Claude Code, Cursor, Grok Build, OpenCode and Antigravity. It never sends prompts itself: the server runs the agent CLIs, and outside agents use its features over MCP. Local build checked: t3 v0.1.1-nightly.20261020.3438.

02 The usual way vs this

Each agent CLI on its own

One terminal per agent, one login each, sessions die with the shell, nothing reachable from a phone, no shared place for projects and threads.

t3 in front of them

One server for all agents and accounts, a background service that outlives the app, pairing tokens and T3 Connect for other devices, update and doctor commands for the install itself.

03 How it flows

curl install.sh | sh→ t3 (start server, open web app)→ t3 service install→ t3 app . (add this repo)→ t3 pair / t3 connect link→ t3 update→ t3 doctor

Agent logins stay with each CLI: codex login, claude auth login, agent login, grok login, opencode auth login. Antigravity is enabled in Settings.
